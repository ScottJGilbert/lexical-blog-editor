## Overview

Styling viewer output is largely left up to the user, and a template is provided below for this purpose; however, for ease of use, the package includes two sets of base viewer styles that can be either used alone or extended as needed.

The first style set, ViewerTheme.css, is designed to provide a minimal amount of styling as necessary to ensure all blog components render properly. It is highly recommended to include this stylesheet if you are not a pro at CSS or only want to make a few small adjustments to the output. The second style set, ViewerThemeComplete.css, provides a complete set of plug-and-play styles that can be dropped directly onto a page without need for additional CSS.

### Basic Setup

To import the included viewer styles:

```javascript
// For displaying basic viewer output content
import "@scottjgilbert/lexical-blog-editor/styles/ViewerTheme.css";

// For more complete, production-ready viewer output content
import "@scottjgilbert/lexical-blog-editor/styles/ViewerThemeComplete.css";

// Additional user-created styles can go below here - they must go below included styles to ensure proper overrides
import "./my-custom-styles.css";
```

## Output Styling

### Default Output Styles

To render viewer content with proper styling:

```tsx
import { Viewer } from "@scottjgilbert/lexical-blog-editor/viewer";
import "@scottjgilbert/lexical-blog-editor/styles/ViewerTheme.css";
import "@scottjgilbert/lexical-blog-editor/styles/ViewerThemeComplete.css"; // Optional

function DisplayContent({ editorStateJson }) {
  return <Viewer state={editorStateJson} />;
}
```
