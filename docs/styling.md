## Overview

Styling output HTML is largely left up to the user, and a template is provided below for this purpose; however, for ease of use, the package includes a set of basic output styles that can be either used alone or extended as needed.

### Basic Setup

To import the included output styles:

```javascript
// For displaying basic output content
import "@scottjgilbert/lexical-blog-editor/styles/output.css";

// For displaying more complete, production-ready output content
import "@scottjgilbert/lexical-blog-editor/styles/complete.css";

// Additional user-created styles can go below here - they must go below included styles to ensure proper overrides
import "./my-custom-styles.css";
```

## Output Styling

### Default Output Styles

To render editor content with proper styling:

```tsx
import "@scottjgilbert/lexical-blog-editor/styles/output.css";
//import "@scottjgilbert/lexical-blog-editor/styles/complete.css"; // For more complete styles

function DisplayContent({ htmlContent }) {
  return (
    <div
      className="lexical-output"
      dangerouslySetInnerHTML={{ __html: htmlContent }}
    />
  );
}
```
